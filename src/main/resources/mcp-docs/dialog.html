Conexão com o servidor MCP

Tudo roda no seu navegador: as credenciais vão direto ao servidor MCP e ao provedor OAuth, sem passar pelo backend desta aplicação. A configuração fica só nesta aba (sessionStorage); o client secret nunca é gravado.

Servidor

URLs relativas usam este servidor. Para outra origem, libere CORS lá e exponha o header Mcp-Session-Id.

Autenticação

O token endpoint do provedor precisa aceitar CORS desta origem (em geral é a configuração "Web origins"/"allowed origins" do client).

Headers personalizados

Enviados em todas as requisições (ex.: X-API-Key, X-Tenant). Sobrescrevem o Authorization gerado acima.

Metadata (_meta) padrão

JSON enviado em params._meta de cada tools/call (no Spring AI chega em parâmetros McpMeta). Pode ser alterado por chamada.
